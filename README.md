# Stories from Jaunty and Other Notable Addresses

Spoken stories from people who played the clubs. One large Record button. The recording is kept centrally, not on the phone.

## Accounts

There is a database.

In the builder preview it is temporary. A registration there is forgotten when the preview restarts. Sign in again only works on a published copy, which uses a real database and keeps the account.

Use the same email and password each time. Stories already saved stay with that account.

## Run it

```bash
npm install
npm run dev
```

The app is meant to be published from the builder. This repository is the source, so it can be shared. It does not contain the recordings.
